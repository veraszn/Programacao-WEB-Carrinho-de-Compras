O Carrinho que Lembra de Você é uma aplicação web desenvolvida como parte da Atividade 02, com o objetivo de explorar conceitos de desenvolvimento back-end e front-end na construção de uma experiência de compra mais intuitiva e personalizada.

O projeto busca unir tecnologia, organização e praticidade, utilizando JavaScript e tecnologias web para desenvolver uma aplicação funcional, com foco na interação entre usuário e sistema.

Projeto acadêmico em desenvolvimento.
